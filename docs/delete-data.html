Delete Your Data

Last updated: 17 May 2026

This page explains how to delete data created by ScoreWise, developed by AppStoneLab. ScoreWise does not use accounts, so there is no profile to delete — only locally-stored gameplay and optional live-session broadcasts.

1. Delete all in-app history

This wipes every session, round, and player name stored on your device.

  1. Open ScoreWise.
  2. Tap Settings from the home screen.
  3. Scroll to the Data section.
  4. Tap Delete all history.
  5. Confirm the prompt.

2. Delete a single session (and its live broadcast)

If you only want to remove one session — including any live-share copy hosted on Firebase — delete it from history.

  1. Open ScoreWise.
  2. Tap History from the home screen.
  3. Swipe the session row left, or long-press and choose Delete.
  4. Confirm. The session is removed from your device immediately and from the live-share server within a few seconds.

3. Uninstall the app

Uninstalling ScoreWise permanently removes everything the app stored on your device. Any live-share broadcasts you started will auto-expire (see retention table below).

  1. On Android: long-press the app icon → Uninstall, or go to Settings → Apps → ScoreWise → Uninstall.
  2. On iOS: long-press the app icon → Remove App → Delete App.

4. Email request

If you cannot reach the in-app controls, email dbvaghani@gmail.com with the 8-character live-session code (format XXXX-XXXX) you want deleted. We will purge it from the live-share server within 7 days and confirm by reply.

What gets deleted vs. kept

Data Where it lives Deleted by Retention if you do nothing
Player names, rounds, scores, session history On your device (Hive storage) Step 1, 2, or 3 Until you delete or uninstall
Live-session broadcast (player names, rounds, timestamps) Firebase Realtime Database Step 2, 3, or 4 Auto-purged after 30 days of inactivity
Anonymous Firebase user ID Firebase Auth (random ID, no profile) Step 3 (uninstall) No personal data attached; expires with the app install
Advertising identifier Held by your device OS and Google AdMob Reset in device settings (Android: Settings → Google → Ads; iOS: Settings → Privacy → Tracking) Controlled by your device, not by this app
